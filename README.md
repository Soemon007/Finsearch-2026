### Overview
This project compares two fundamentally different methods of forecasting financial time series:
- Using DQNs
- Using ARIMA

Each model is evaluated on its ability to generate profitable trading signals and is assessed using standard backtesting metrics such as cumulative returns, Sharpe ratio, and maximum drawdown.
